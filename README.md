A tiny Python program that writes a one-line review of the most boring everyday object, 146 characters, to /output/entry.txt for make.fun's The Most Boring Object, Reviewed in One Line bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
